 ```bash

 ```
2. Copiar link de repositorio 
 ```bash
 https://github.com/jdlzo/Game.git
 ```
3. Para este caso yo use git bash, si no quieres hacerlo por comando mas adelante estan los pasos para git desktop

```bash
git -C C:\Game clone https://github.com/jdlzo/Game.git
```
4. Dentro de git bash ubicate en la carpeta donde se clono el repositorio para verificar que se clono corrrectamente
```bash
cd C:\game\Game
```
